# Khöömei Cold Plunge

A tiny, single-screen ice-swim arcade game: steer through floes, collect hot tea, and sustain an overtone before your core heat—and your confidence—hit zero.

## Play

Open `index.html` or serve this folder with any static web server. The game is also published on GitHub Pages.

- **WASD / arrow keys:** swim
- **Hold Space:** chant to slow the chill (uses breath)
- **R:** dive again
- **Sound button:** mute/unmute
- **Touch:** use the on-screen pad and hold-to-chant button

Survive for 60 seconds. Hot tea warms you and restores breath; ice floes do the opposite. Your voice climbs in pitch as the cold meter rises.

## Audio

`assets/kargyraa.wav` is the throat-singing sample supplied by the requester for this game (original filename: `240917__nemaavla__overtone-singing-kargyraa.wav`). Pitch shifting is done live with the Web Audio API. Please check the recording's original license/attribution before reusing the audio elsewhere.
